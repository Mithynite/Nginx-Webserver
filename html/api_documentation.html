API Documentation

Base URL: http://54.93.165.202/api

Endpoints

GET /api/blog

Explanation: Retrieve all blog posts

Response: 
Status: 200
[
  {
    "id": "integer",
    "title": "string",
    "content": "string",
    "author_name": "string",
    "author_surname": "string",
    "timestamp": "ISO 8601 string"
  }
]

POST /api/blog

Explanation: Create a new blog post

Request: 
{
  "title": "string",
  "content": "string",
  "author_name": "string",
  "author_surname": "string"
}
Response: 
Status: 201
{
  "message": "Blog added successfully",
  "postId": "integer"
}

GET /api/blog/:id

Explanation: Retrieve a blog post by ID

Response: 
Status: 200
{
  "id": "integer",
  "title": "string",
  "content": "string",
  "author_name": "string",
  "author_surname": "string",
  "timestamp": "ISO 8601 string"
}

DELETE /api/blog/:id

Explanation: Delete a blog post by ID

Response: 
Status: 200
{
  "message": "Blog post deleted successfully"
}

PATCH /api/blog/:id

Explanation: Partially update a blog post by ID

Request: 
{
  "title": "string (optional)",
  "content": "string (optional)"
}
Response: 
Status: 200
{
  "message": "Blog post updated successfully"
}
